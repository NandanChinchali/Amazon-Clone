# Amazon Clone

A frontend recreation of the Amazon e-commerce homepage built using HTML and CSS.  
The project focuses on replicating the structure, layout, navigation, product sections, and overall visual experience of a modern e-commerce platform.

## Overview

This project was developed as a frontend practice project to strengthen my understanding of webpage structure, CSS layouts, Flexbox, reusable UI sections, and responsive design.

## Features

- Amazon-inspired navigation bar
- Location and delivery section
- Product search interface
- Shopping cart section
- Hero banner
- Product/category cards
- Multiple product sections
- Responsive page layout
- Amazon-inspired styling and UI structure

## Tech Stack

- **HTML** – Page structure and semantic elements
- **CSS** – Styling, layouts, Flexbox, spacing, and responsiveness
- **Font Awesome** – Icons
- **VS Code** – Development environment
